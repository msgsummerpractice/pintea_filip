# Save Case Implementation Plan

> **Execution:** Use subagent-driven development to implement this plan task-by-task.

**Goal:** Extend the backend case creation flow so it stores a generated case identifier, an empty colleague assignment placeholder, and returns a safe persistence error without breaking the existing transactional save graph.

**Architecture:** Reuse the existing Django REST create endpoint, serializer validation, and `create_case` service. Keep the save path centered in the current transactional service, extend the `Case` model with story-specific metadata, and adjust the response contract at the API boundary.

**Tech Stack:** Django 5, Django REST Framework, PostgreSQL, pytest

**Design Spec:** `documentation/spec-driven/specs/2026-07-23-save-case-design.md`

**Requirements:**
- Add a unique generated `case_id` field to `Case`.
- Add an initially empty colleague assignment field to `Case`.
- Preserve the existing relational graph and status behavior.

**Implementation:**

```python
def generate_case_id() -> str:
    return f"CASE-{uuid4().hex[:12].upper()}"


class Case(models.Model):
    case_id = models.CharField(max_length=17, unique=True, default=generate_case_id, editable=False)
    assigned_colleague = models.CharField(max_length=255, blank=True, default="")
```

**Testing:**

```python
def test_case_business_identifier_and_colleague_defaults(case: Case) -> None:
    assert case.case_id.startswith("CASE-")
    assert case.assigned_colleague == ""
```

### Task 2: Expose Save Metadata and Handle Persistence Failures

**Files:**
- Modify: `backend/apps/cases/api/views.py`
- Modify: `backend/tests/test_case_creation_api.py`

**Requirements:**
- Return the generated case ID and created timestamp on successful submit.
- Preserve the existing compensation payload.
- Return a safe error message when persistence fails.
- Prove rollback still occurs when the database save path fails.

**Implementation:**

```python
try:
    case = create_case(serializer.validated_data)
except DatabaseError:
    return Response(
        {"detail": "Unable to save case at this time."},
        status=status.HTTP_500_INTERNAL_SERVER_ERROR,
    )

return Response(
    {
        "id": case.case_id,
        "caseId": case.case_id,
        "createdAt": case.created_at.isoformat(),
        "status": case.status,
        "compensation": {...},
    },
    status=status.HTTP_201_CREATED,
)
```

**Testing:**

```python
assert response.json()["caseId"] == created_case.case_id
```
